# A LaTeX package is usually released under the LaTeX Project Public License, which leaves the documents typeset with it free

The LaTeX Project Public License, LPPL, is the licence of LaTeX itself and of most packages on CTAN.
The current version is 1.3c, with the SPDX identifier `LPPL-1.3c`.

The licence covers distributing and modifying the package.
Running the package is outside its scope, so a document typeset with a package under the LPPL may carry any licence.

A person other than the maintainer may distribute a changed version on four conditions.

1. The changed file identifies itself, clearly and without ambiguity, as a modified version of the original, in its name or in the message it prints.
2. The changed file holds prominent notices that say what changed.
3. Nothing in the changed version implies that the authors of the original support it.
4. The changed version comes with the original, or with the information to obtain it.

A package declares its maintenance status.
The status `author-maintained` lets only the copyright holder maintain it.
The status `maintained` names a current maintainer who takes error reports.
When the maintainer cannot be reached for six months, the package becomes `unmaintained`, and another person may take it over after announcing the intent and waiting three months for an objection.

A package declares the licence with a copyright notice, the year and a statement like the following, at the top of its source file:

```latex
% Copyright (C) 2026 Firstname Lastname
%
% This work may be distributed and/or modified under the
% conditions of the LaTeX Project Public License, either version 1.3
% of this license or (at your option) any later version.
% The latest version of this license is in
%   https://www.latex-project.org/lppl.txt
%
% This work has the LPPL maintenance status `maintained'.
% The Current Maintainer of this work is Firstname Lastname.
```

The LPPL is not compatible with the GPL, as knowledge item `public-knowledge-base/licences/licence-compatibility.md` says.
A package may also take a licence of software, such as `MIT`, which lets others change it under any name.
